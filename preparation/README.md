# Optional instructor-only portrait preparation

LivePortrait is not needed to build, test, or run the workshop. The final portrait is still pending.

Use the official [LivePortrait repository](https://github.com/KlingAIResearch/LivePortrait) for the current supported environment, installation steps, model terms, and image/driving-video workflow. Keep its separate environment and model weights outside this student repository. Review licenses of the code, weights, source portrait, and driving material before publishing outputs.

Prepare a controlled baseline crop, then experiment with retargeting and suitable driving examples for the expressions in the manifest. These are our desired expressions, not a promise of built-in named presets. A wink or eye roll may need different driving material. Stylized heart eyes in the illustrated love reaction should be translated to an affectionate human expression rather than distorted eyes. Record the exact upstream commit, model versions, source permissions, settings/driving asset IDs, crop, export steps, and output checksums alongside your generated assets when available.

Export still images first. Inspect identity consistency and eye/mouth artifacts at full size and in the viewer. Match each output with the expression description. Do not set the manifest's temporary flag to false until every output passes visual review and redistribution rights are documented in docs/assets.md.
