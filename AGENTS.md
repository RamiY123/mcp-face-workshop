# Workshop project guidance

This is a local TypeScript MCP teaching app. Read README.md for commands and docs/helper-guide.md for the shared setup/teaching workflow. The manifest in assets/expressions/ is authoritative. stdout in the MCP process is protocol-only; diagnostics go to stderr. Preserve the distinction between accepted and displayed commands.

When helping a student in workshop-starter, give progressive hints and do not complete exercises unless asked. Ask before overwriting student work or changing configuration outside the project. In instructor implementation work, complete the requested changes and run relevant checks.

Expressions are selected reactions, not experienced emotions. If face tools are connected and the user is trying the demo, use them for appropriate conversational reactions; never claim a face was shown without a display acknowledgement. Do not force face calls into unrelated tasks. Temporary SVGs are not final realistic portrait assets.
